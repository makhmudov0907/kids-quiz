# Выбираю безопасное действие · 3–4 класс

Готовая интерактивная викторина «Безопасный и вежливый интернет».
Пять вопросов: три с выбором одного ответа и два «Да / Нет».
После ответа появляются проверка и объяснение. В конце — балл из пяти и повторная попытка.

## Как опубликовать на GitHub Pages

1. Создайте публичный репозиторий с именем `internet-quiz-3-4`.
2. Загрузите в него содержимое этой папки. Файл `index.html` должен находиться в корне репозитория, а не внутри дополнительной папки. ZIP загружать не нужно — сначала распакуйте архив.
3. Сохраните файлы в ветку `main`.
4. Откройте **Settings → Pages**. В **Source** выберите **Deploy from a branch**, затем **main** и **/(root)**, нажмите **Save**.
5. Дождитесь публикации и откройте ссылку **Visit site** в разделе Pages.

Документация GitHub:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что внутри

- `index.html` — вся игра, оформление, картинки, шрифты и вопросы в одном файле. Его можно открыть обычным браузером и без загрузки на сервер.
- `.nojekyll` — служебный файл для публикации готового HTML.
- `OFL-Rubik.txt` — лицензия использованного шрифта Rubik.
- `README.md` — эта инструкция.

Посетителям сайта не нужны аккаунты ChatGPT или GitHub. Серверная часть и установка программ не требуются.
Результат виден на устройстве ученика и не отправляется учителю автоматически. Его можно показать или распечатать.
Ссылка «Памятка к уроку» открывает подготовленную доску Padlet; для этого перехода нужен интернет.

Иллюстрации созданы с помощью ИИ для этого учебного комплекта. Шрифт Rubik распространяется по SIL Open Font License 1.1; уведомление также включено в HTML.
